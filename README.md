# ⚡ Speed Typing Test WebApp

A sleek, responsive, and minimalist web-based typing speed application built to test and improve keyboard accuracy and speed in Words Per Minute (WPM) / Words Per Second (WPS).

[**Live Demo 🚀**](https://rahulgarg10.github.io/Speed_Typing_Test_WebApp/)

---

## 🚀 Features

*   **Dynamic Difficulty Modes**: Choose between **Easy**, **Medium**, and **Hard** settings to match your current skill level.
*   **Real-time Analytics**: Displays live **WPS (Words Per Second)** performance and an **Accuracy Percentage** calculation as you type.
*   **Built-in Timer**: A dedicated **30-second countdown** window to challenge your high score under time pressure.
*   **Immersive Dark Mode**: Features a **🌙 Toggle Theme** switcher to prevent eye strain during late-night practice sessions.
*   **Completely Responsive**: Built with a mobile-friendly structure that scales elegantly across desktops, tablets, and smartphones.

---

## 🛠️ Built With

*   **HTML5** - Structured semantic semantic layout.
*   **CSS3** - Custom properties, responsive flexbox layout, and seamless light/dark mode transitions.
*   **Vanilla JavaScript (ES6+)** - Reactive event handling, accurate live stat calculation algorithms, and interval timers.

## 📦 Installation & Local Setup

To run this application locally on your computer without installing heavy dependencies, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the project directory:**
   ```bash
   cd Speed_Typing_Test_WebApp
   ```

3. **Open the application:**
   Simply double-click the `index.html` file to run it locally in your default web browser, or use an extension like **Live Server** in VS Code.

---

## 🕹️ How to Use

1. Click the **Start Test** button to initialize the typing challenge.
2. Observe the generated text block corresponding to your selected difficulty level (**Easy, Medium, or Hard**).
3. Type the text precisely inside the input field.
4. Keep track of your live **WPS** and **Accuracy** stats before the **30s timer** runs out!
